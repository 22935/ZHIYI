## 归档规则

1. **原文保全**：合并稿正文与原文逐字一致，只做标题层级下移与相对链接改写；不覆盖、不改写当时的结论与失败记录。
2. **可追溯**：每篇合并稿末尾有来源清单；原文件名与日期保留在 `<!-- 原始记录：… -->` 标记和文末表格中。
3. **不再维护**：归档文档不随代码演进更新；其中的命令、路径与验收结论仅代表当时状态。
4. **不删证据**：归档只改变位置，不删除内容；Git 历史始终可查。
