# OScode `/compact` 接入记录

OScode 输入框支持输入 `/compact` 后发送；输入 `/` 或 `/co` 时提供命令按钮。命令由界面拦截，不作为用户消息入库，不启动文件、终端或 ACG 操作。

## 行为与边界

- 新增 `POST /ai/chat/compact`，经现有 Java 认证代理转发到 Python；使用当前模型连接和同一 TS 压缩核心。
- `force=true` 绕过自动压力阈值。手动保留比例按当前历史长度计算，继续保留近期完整轮次、保护内容及摘要校验。
- 摘要生成禁用工具。失败时保留原上下文；近期内容不足时明确显示无需压缩。
- 校验通过的“摘要＋近期消息”在当前页面的 Chat store 内保存，后续文本和 SSE 请求通过现有 `context` 字段使用该投影，并追加压缩后的新增轮次。
- 完整显示记录和数据库历史保留；未新增数据库迁移。摘要不跨设备持久化；刷新页面后恢复完整原始上下文。
- 投影按会话和模型连接隔离。源历史修改或模型设置变化使其失效；切换会话后取消请求并忽略迟到结果。最多保存八份页面内投影。
- UI 显示压缩进度、估算 Token 变化以及无可压缩内容或失败原因。Token 数包含保守估计，不代表精确计费量。

## 开关与运行条件

`OSCODE_CONTEXT_COMPACTION_MANUAL_ENABLED=true` 为手动入口默认值，可以单独关闭。自动开关 `OSCODE_CONTEXT_COMPACTION_ENABLED` 仍默认关闭。模型窗口配置、Node >=24.9 及 `apps/oscode-context` 的依赖要求沿用原实现。未知模型窗口应在 `OSCODE_CONTEXT_COMPACTION_MODELS` 中配置，不能猜测。

新路由和配置需要重启 Python AI 服务加载。Java 使用已有通用代理，无需新增路由。此次未重启正在运行的桌面服务，也未进行真实 Provider 付费调用或桌面端到端验收。
