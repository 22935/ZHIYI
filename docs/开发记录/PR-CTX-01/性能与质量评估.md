- 摘要 1 次，Provider 实测总成本 4222 Token，耗时 4492.881 ms。
- 引擎预算估算 20960 → 1107；exactContentTokenization=False，wireTokenCountExact=False。
- keep REST、src/context.ts、add race tests、1500 四项检查均保留（4/4）；只验证这个小样例，不宣称一般语义无损。

## 生产风险与准入结论

1. DeepSeek 本次使用保守 UTF-8 文本预算，可能过早压缩；匹配 tokenizer、Provider wire 和图像计价还需校准。
2. 真实质量样例只有一个，复杂代码/对抗历史/失败工具/多模态的事实保留未全面证明。
3. 旧多模态与不透明项会形成保护边界；超大当前用户消息、系统指令或未完成周期不能安全缩小时会明确失败。
4. 第一阶段无跨 HTTP 摘要复用；摘要延迟和成本可能重复，当前不建议默认开启。
5. Node 24 与 npm 锁定依赖需纳入后续发布装配；本轮没有改装配或部署。
6. 既有聊天存储不完整保存工具 wire branch；压缩器不补造该数据，也不承诺跨服务重启恢复该分支。
7. 全量门禁仍失败；可继续隔离/合成数据验证，不具备默认开启或正式真实用户验收条件。
