### 记忆器核心结构（已梳理）
- 定位：把上下文连续性从模型上下文窗口剥离，升级为可版本化、可审计的运行时控制平面。
- 六类记忆（按职责）：Working / Episodic / Semantic / Procedural / Profile·Constraint / Evidence·Artifact
- 三级稳定性（按生命周期）：Step 级 → Task/Run 级 → 跨 Task 级。**六类与三级正交**，文档未点明，需补一句说明。
- 三个控制平面：在线上下文平面（准入·召回·装配）、异步巩固平面（Capsule·晋升）、治理与生命周期平面（过期·冲突·遗忘）。
- 唯一出口：ContextPack（单次调用的唯一系统上下文投影，可解释可重建）。
- 写回：MemoryWriteBatch 单事务（状态 revision + 情节事件 + 引用登记 + 审计事件），强一致失败整批回滚。
- 检索：硬门控 → 关键词+向量+图关联并行召回 → RRF 融合（常数 60，候选上限 100）→ 预算分区装配 → 校验交付。
- 复杂度 O(T + N×Q + N×D + NlogN)。
